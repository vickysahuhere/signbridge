  <files>src/vision/velocityGate.js, test/velocityGate.test.js</files>
  <read_first>tech.md, appflow.md</read_first>
  <action>
    - Create `src/vision/velocityGate.js`:
      - Export enum `MOTION_STATES = { IDLE: 'IDLE', SIGNING_ACTIVE: 'SIGNING_ACTIVE', PAUSE_COUNTDOWN: 'PAUSE_COUNTDOWN', IDLE_COMMIT: 'IDLE_COMMIT' }`.
      - Export class `VelocityGate(options = {})`:
        - Options: `activeThreshold = 0.015`, `idleThreshold = 0.008`, `commitDurationMs = 1200`, `windowSize = 5`.
        - `update(leftWrist, rightWrist, timestamp)`:
          - Calculates frame-to-frame Euclidean distance for active wrists.
          - Maintains rolling 5-frame average velocity ($v_{\text{rolling}}$).
          - If $v_{\text{rolling}} \ge \text{activeThreshold}$, transitions to `SIGNING_ACTIVE` and resets idle timer.
          - If $v_{\text{rolling}} < \text{idleThreshold}$ and previously signing, starts pause countdown.
          - If pause duration $\ge 1200\text{ms}$, emits `IDLE_COMMIT`.
          - Returns `{ state, rollingVelocity, pauseProgress (0.0 to 1.0), elapsedPauseMs }`.
    - Create `test/velocityGate.test.js`:
      - Test 1: Moving wrists emit `SIGNING_ACTIVE`.
      - Test 2: Stationary wrists start `PAUSE_COUNTDOWN` with incrementing `pauseProgress`.
      - Test 3: Stationary wrists after 1250ms emit `IDLE_COMMIT`.
    - Run `npm test`.
  </action>
  <verify>npm test passes with velocityGate unit tests included</verify>
  <acceptance_criteria>

    - test/velocityGate.test.js validates transitions to SIGNING_ACTIVE, PAUSE_COUNTDOWN, IDLE_COMMIT
