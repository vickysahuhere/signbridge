  <name>Task 1: Build WebRTCManager with STUN/TURN & RTCDataChannel</name>
  <files>src/network/webrtcManager.js, test/webrtcManager.test.js</files>
  <read_first>tech.md, appflow.md</read_first>
  <action>
    - Create `src/network/webrtcManager.js`:
      - Define STUN configuration:
        `iceServers: [{ urls: ['stun:stun.cloudflare.com:3478', 'stun:stun.l.google.com:19302'] }]`.
      - Class `WebRTCManager`:
        - `constructor({ onMessage, onStatusChange, onFallbackTrigger, sendSignaling })`:
          - Initializes state: `peerConnection = null`, `dataChannel = null`, `status = 'idle'`, `isInitiator = false`.
        - `initiateCall()`:
          - Creates `RTCPeerConnection`.
          - Creates `dataChannel = pc.createDataChannel('isl-chat', { ordered: true })`.
          - Sets up data channel event listeners (`onopen`, `onmessage`, `onclose`, `onerror`).
          - Creates SDP offer, sets local description, sends via `sendSignaling({ type: 'OFFER', sdp: offer })`.
          - Handles ICE candidate events and transmits via `sendSignaling({ type: 'CANDIDATE', candidate })`.
        - `handleSignalingMessage(message)`:
          - If `message.type === 'OFFER'`: creates `RTCPeerConnection`, listens for `ondatachannel`, sets remote description, creates SDP answer, sends via `sendSignaling({ type: 'ANSWER', sdp: answer })`.
          - If `message.type === 'ANSWER'`: sets remote description.
          - If `message.type === 'CANDIDATE'`: adds ICE candidate.
        - `sendMessage(packet)`:
          - If `dataChannel?.readyState === 'open'`: sends JSON stringified packet directly over UDP (<20ms).
          - Else: invokes `onFallbackTrigger(packet)` to send via Supabase WebSocket broadcast (`NETW-03`).
        - `sendPartialSigning(glosses, previewText, senderName)`:
          - Transmits packet: `{ type: 'PARTIAL_SIGNING', glosses, previewText, sender: senderName, timestamp: Date.now() }` (`NETW-04`).
        - `close()`: Cleans up peer connection and channels.
    - Create `test/webrtcManager.test.js`:
      - Test packet creation and serialization for `PARTIAL_SIGNING`, `COMMITTED_MESSAGE`, and `TEXT_REPLY`.
      - Test fallback trigger when dataChannel is closed.
      - Test message deserialization and type routing.
  </action>
