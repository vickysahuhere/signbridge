  <name>Task 1: Implement GlossBufferManager with Deduplication & Spelling Concatenation</name>
  <files>src/nlp/glossBufferManager.js, test/glossBufferManager.test.js</files>
  <read_first>tech.md, appflow.md</read_first>
  <action>
    - Create `src/nlp/glossBufferManager.js`:
      - Class `GlossBufferManager`:
        - `constructor()`: Initializes `this.buffer = []`.
        - `push(token, type = 'word')`:
          - If token is empty/null, return false.
          - If token is a single uppercase letter (`/^[A-Z0-9]$/`) and the last item in buffer is marked as `isSpelled: true`:
            - Append to the spelled word (e.g. `'R'` + `'A'` -> `'RA'`).
          - Otherwise, check if `token === lastToken` (adjacent duplicate):
            - If identical to the last token, reject / ignore (`LING-01`).
            - Else, push `{ gloss: token, type, isSpelled: type === 'letter', timestamp: Date.now() }`.
          - Return true if added/updated.
        - `undo()`: Removes the last entry in `buffer`. If the last entry is a spelled word with multiple letters, optionally removes the last character or whole word. Returns removed token.
        - `clear()`: Empties `this.buffer = []`.
        - `getGlosses()`: Returns array of string glosses `this.buffer.map(item => item.gloss)`.
        - `getItems()`: Returns full buffer items with metadata.
        - `size()`: Returns buffer length.
        - `isEmpty()`: Returns `this.buffer.length === 0`.
    - Create `test/glossBufferManager.test.js`:
      - Test: rejects null/empty tokens.
      - Test: deduplicates adjacent identical tokens (`["HELLO", "HELLO"]` -> `["HELLO"]`).
      - Test: permits non-adjacent repeats (`["HELLO", "YOU", "HELLO"]`).
      - Test: concatenates consecutive single-letter fingerspelling tokens into a single word (`'R'`, `'A'`, `'H'`, `'U'`, `'L'` -> `'RAHUL'`).
      - Test: `undo()` correctly pops the last token.
      - Test: `clear()` resets the buffer to empty.
  </action>
  <verify>node --test test/glossBufferManager.test.js passes all assertions</verify>

    - Create `src/nlp/islSentenceFormatter.js`:
      - Tagging & Lexicon Map covering the 50 ISL vocabulary words + fingerspelled entities:
        - Pronouns: `I_ME` -> `"I"`, `YOU` -> `"you"`, `WE` -> `"we"`, `THEY` -> `"they"`
        - Question markers: `WHAT`, `WHERE`, `WHO`, `WHY`, `WHEN`, `HOW`
        - Actions & Verbs: `GO` -> `"go"`, `COME` -> `"come"`, `EAT` -> `"eat"`, `DRINK` -> `"drink"`, `HELP` -> `"help"`, `WORK` -> `"work"`, `STUDY` -> `"study"`, `SLEEP` -> `"sleep"`, `WAIT` -> `"wait"`, `SEE` -> `"see"`, `KNOW` -> `"know"`, `UNDERSTAND` -> `"understand"`, `WANT` -> `"want"`
        - Objects/Places: `HOSPITAL`, `DOCTOR`, `MEDICINE`, `POLICE`, `WATER`, `FOOD`, `HOME`, `SCHOOL`, `NAME`, `FRIEND`, `FAMILY`
        - Temporal: `TODAY`, `TOMORROW`, `YESTERDAY`, `TIME`
        - Greetings: `HELLO`, `GOOD_MORNING`, `WELCOME`, `THANK_YOU`, `PLEASE`, `SORRY`
        - Adjectives/Modals: `YES`, `NO`, `GOOD`, `BAD`, `HAPPY`, `SAD`
      - Implement `formatIslSentence(glosses)`:
        - If `!glosses || glosses.length === 0`, return `""`.
        - Handle single-word expressions (`"HELLO"` -> `"Hello!"`, `"THANK_YOU"` -> `"Thank you!"`, `"YES"` -> `"Yes."`, `"NO"` -> `"No."`).
        - **Rule 1: WH-Final Question Restructuring (`LING-04`)**:
          - If the last token is a WH-word (or contains a WH-word):
            - `["YOU", "NAME", "WHAT"]` -> `"What is your name?"`
            - `["HOSPITAL", "WHERE"]` -> `"Where is the hospital?"`
            - `["YOU", "HOW"]` -> `"How are you?"`
            - `["HELP", "HOW"]` -> `"How can I help you?"`
            - `["YOU", "GO", "WHERE"]` -> `"Where are you going?"`
        - **Rule 2: SOV to SVO Restructuring (`LING-03`)**:
          - When sequence matches `Subject + Object + Verb`:
            - `["I_ME", "WATER", "WANT"]` -> `"I want water."`
            - `["I_ME", "HOSPITAL", "GO"]` -> `"I am going to the hospital."`
            - `["I_ME", "FOOD", "EAT"]` -> `"I am eating food."`
            - `["YOU", "MEDICINE", "WANT"]` -> `"Do you want medicine?"`
        - **Rule 3: Adjective & Predicate Clauses**:
          - `["TODAY", "I_ME", "HAPPY"]` -> `"I am happy today."`
          - `["I_ME", "SAD"]` -> `"I am sad."`
          - `["FAMILY", "GOOD"]` -> `"My family is good."`
        - **Rule 4: Greeting prefixes**:
          - `["HELLO", "YOU", "HOW"]` -> `"Hello! How are you?"`
        - **Fallback**:
          - Join tokens with proper casing and trailing period if no pattern matches.
        - Ensure proper English capitalization and terminal punctuation (`.`, `?`, `!`).
      - Export `formatIslSentence` and `islGlossesToEnglish`.
    - Create `test/islSentenceFormatter.test.js`:
      - Test single word greetings and politeness signs.
      - Test SOV to SVO inversion (`["I_ME", "WATER", "WANT"]` -> `"I want water."`).
      - Test SOV motion verbs (`["I_ME", "HOSPITAL", "GO"]` -> `"I am going to the hospital."`).
      - Test WH-question fronting and copula insertion (`["YOU", "NAME", "WHAT"]` -> `"What is your name?"`, `["HOSPITAL", "WHERE"]` -> `"Where is the hospital?"`).
      - Test greetings with questions (`["HELLO", "YOU", "HOW"]` -> `"Hello! How are you?"`).
      - Test fingerspelled noun inclusion (`["NAME", "RAHUL"]` -> `"My name is Rahul."`).
  </action>
