  <action>
    - Create `src/components/KeypointRecorderDrawer.jsx`:
      - Props: `isOpen`, `onClose`, `latestNormalizedFeatures`, `motionState`.
      - State: `labelName` (text input e.g. "A", "NAMASTE"), `isRecording`, `recordedFrames` (array of Float32Array frames), `recordedSamples` (saved list in current session).
      - Recording workflow:
        - User types a label name (default `'A'`).
        - Clicks `[Start 100-Frame Recording]`.
        - Visual 3-second countdown (3... 2... 1... SIGN NOW!).
        - Collects the next 100 frames of `latestNormalizedFeatures` (`Float32Array(240)`).
        - Displays live progress bar (`Recording: 64/100 frames`).
        - Automatically stops when 100 frames are captured and adds sample to `recordedSamples`.
      - Export functionality:
        - `exportJSON(sample)`: Generates and triggers download of `.json` containing:
          `{ label: sample.label, frameCount: 100, featureDim: 240, timestamp: Date.now(), frames: [...] }`.
        - `exportCSV(sample)`: Generates and triggers download of `.csv` with header (`frame,k0_x,k0_y,k0_z,...,k79_z,label`) and 100 rows of normalized landmark values.
        - `exportAllZipOrBatch()`: Fast multi-sample JSON bundle download.
      - Sample library table: displays list of captured gestures in session, timestamp, frame count, and download/delete buttons.
  </action>
  <verify>npm run build succeeds; KeypointRecorderDrawer exports clean React component</verify>
