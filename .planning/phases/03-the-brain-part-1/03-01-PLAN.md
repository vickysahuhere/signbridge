<task type="auto">
  <name>Task 2: Implement Softmax calculation and top-K candidate extraction with unit tests</name>
  <files>src/ai/softmax.js, test/softmax.test.js</files>
  <read_first>src/ai/islAlphabetLabels.js</read_first>
  <action>
    - Create `src/ai/softmax.js`:
      - Export `softmax(logits)`:
        - Subtracts maximum logit $\max_i z_i$ to prevent `Math.exp()` floating-point overflow.
        - Exponentiates and normalizes so output values sum to $1.0$.
        - Returns `Float32Array`.
      - Export `getTopKPredictions(probabilities, labels = ISL_ALPHABET_LABELS, k = 3, threshold = 0.75)`:
        - Sorts predictions in descending order of confidence.
        - Returns array of `{ rank, index, label, confidence, isConfident: confidence >= threshold }`.
        - Calculates top-1 and determines if confidence meets threshold.
    - Create `test/softmax.test.js`:
      - Test 1: Softmax sums to 1.0 on positive, negative, and large logits without NaN.
      - Test 2: Top-3 extraction ranks candidates in descending order with correct labels.
      - Test 3: Flags `isConfident = true` when top candidate >= 0.75, and false when < 0.75.
    - Run `npm test`.
  </action>
  <verify>npm test passes with softmax unit tests</verify>
  <acceptance_criteria>
    - src/ai/softmax.js exports softmax and getTopKPredictions
    - test/softmax.test.js tests numerical stability and threshold gating
    - npm test exits 0
  </acceptance_criteria>
  <done>Softmax probability calculation and top-K ranking mathematically validated</done>
