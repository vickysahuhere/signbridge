  <action>
    - Update `src/workers/vision.worker.js`:
      - Import `ISL_WORD_LABELS` from `../ai/islWordLabels.js`.
      - Import `ConsecutiveConfirmationGate` from `../ai/consecutiveConfirmation.js`.
      - Initialize `const wordConfirmationGate = new ConsecutiveConfirmationGate();`.
      - Initialize `let wordSession = null;` and `let isWordModelReady = false;`.
      - Add `initWordModel(modelPath = '/models/isl_include_50.onnx')` loading model via `ort.InferenceSession.create()` and running warm-up inference `[1, 7200]`.
      - In `processFrame(imageBitmap, timestamp)`:
        - Maintain frame counter `frameCount`.
        - When `motion.state === 'SIGNING_ACTIVE'` AND `ringBuffer.size() >= 30` AND `frameCount % 5 === 0`:
          - Extract `const flatFeatures = ringBuffer.getFlattened();` (`Float32Array(7200)`).
          - Run `const wordOutput = await wordSession.run({ input: new ort.Tensor('float32', flatFeatures, [1, 7200]) });`.
          - Compute top-3 predictions via `getTopKPredictions(wordOutput.output.data, ISL_WORD_LABELS.map(w => w.gloss), 3, 0.75)`.
          - Pass top-1 candidate to `wordConfirmationGate.processCandidate(top1)`.
          - If confirmed, attach `confirmedWord: confirmationResult.word`.
        - Post `wordPredictions: { topCandidates, confirmedWord }` in `LANDMARK_RESULTS`.
    - Update `src/hooks/useVisionWorker.js`:
      - Track `wordPredictions` and `latestConfirmedWord` in state.
      - Expose them in hook return.
  </action>
  <verify>npm run build succeeds without worker bundling errors</verify>
