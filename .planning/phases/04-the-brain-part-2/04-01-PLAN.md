<task type="auto">
  <name>Task 2: Implement 2-step consecutive confirmation gate with unit tests</name>
  <files>src/ai/consecutiveConfirmation.js, test/consecutiveConfirmation.test.js</files>
  <read_first>src/ai/islWordLabels.js, src/ai/softmax.js</read_first>
  <action>
    - Create `src/ai/consecutiveConfirmation.js`:
      - Export class `ConsecutiveConfirmationGate(options = {})`:
        - Options: `confidenceThreshold = 0.75`, `requiredConsecutive = 2`, `cooldownFrames = 6`.
        - `processCandidate(top1Prediction)`:
          - If candidate has `confidence >= confidenceThreshold`:
            - If matches `previousCandidate?.label`:
              - Increment `consecutiveCount`.
              - If `consecutiveCount >= requiredConsecutive` and not currently in cooldown:
                - Emit confirmed sign event: `{ confirmed: true, word: top1Prediction.label, confidence: top1Prediction.confidence }`.
                - Enter cooldown to prevent re-triggering the same continuous sign immediately.
              - Else return `{ confirmed: false, pending: true, count: consecutiveCount }`.
            - Else:
              - Reset `consecutiveCount = 1`, store as current candidate.
          - If confidence < threshold:
            - Reset pending candidate.
          - Return status object.
        - Method `reset()`: resets candidate and cooldown state.
    - Create `test/consecutiveConfirmation.test.js`:
      - Test 1: Single high-confidence prediction does NOT confirm immediately (pending count 1).
      - Test 2: Two consecutive matching predictions with >=0.75 confidence trigger `confirmed: true`.
      - Test 3: Fluctuating label (e.g. 'HELLO' followed by 'WATER') resets counter and rejects confirmation.
      - Test 4: Low confidence (<0.75) resets pending state.
    - Run `npm test`.
  </action>
  <verify>npm test passes with consecutiveConfirmation test suite</verify>
  <acceptance_criteria>

    - test/consecutiveConfirmation.test.js passes all 4 test cases
